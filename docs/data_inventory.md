## Тематика корпуса

- Архитектура Kubernetes (объекты, слои управления, сетевая модель)
- Частые вопросы (FAQ) по эксплуатации
- Безопасность Kubernetes (RBAC, сетевые политики, секреты)
- Observability и мониторинг
- Деплой приложений и сервисы

## Назначение

Корпус используется для обучения RAG-ассистента в дипломном проекте (Блок 5.5). Документы содержат техническую документацию Kubernetes, необходимую для ответов на вопросы DevOps-инженеров.
