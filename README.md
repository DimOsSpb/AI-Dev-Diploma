# Проект дипломной работы
---
## ИИ-ассистент информационной инфраструктуры на основе LLM

### Тема диплома:

**«Разработка и исследование интеллектуального ассистента мониторинга и диагностики ИТ-инфраструктуры»**

### Описание:

Ассистент предоставляет единый интерфейс (чат, в перспективе голосовой ввод/вывод) для получения фактической информации о состоянии информационной инфраструктуры. В данной версии ассистент поддерживает три адаптера для работы с кластерами Proxmox, Kubernetes и отдельными Linux-хостами. Ассистент работает в режиме read-only, не производя изменений.

Пользователь задаёт вопросы естественным языком («Покажи нагрузку на нодах», «Почему Pod перезапустился?», «Что за ошибки в логах за последний час?»). Ассистент через адаптеры собирает данные из целевых систем, анализирует их с помощью LLM (на локальном GPU) и выдаёт краткий ответ с рекомендациями. Дополнительно ассистент поддерживает RAG по внутренней документации, wiki, issues.

### Обоснование выбора:

- **Актуальность**. В администрировании различных on‑premise инфраструктур значительную долю времени занимает ручной поиск информации, анализ логов и метрик по нескольким системам. Существующие алерты и дашборды не отвечают на сложные контекстные вопросы и требуют значительных временных затрат от администраторов.

- **Уникальность**. Предлагаемый ассистент ориентирован именно на информационную поддержку, а не на автоматизацию действий. Это снижает риски и повышает доверие к ИИ‑решениям в инфраструктуре. При необходимости, функциональность изменений с подтверждением, может быть добавлена в будущем.

- **Практическая польза**. Моя работа постоянно связана с описанными системами, поэтому ассистент будет реально использоваться, сокращая время диагностики и уменьшая количество рутинных запросов к документации.

- **Соответствие курсу**. Проект охватывает все ключевые темы: создание API, интеграцию с внешними системами, использование LLM, реализацию ассистента с инструментами (tools), RAG, а также опционально — голосовой ввод/вывод.

- **Новизна**. Применение LLM в роли «информационного штурмана» для инфраструктурных администраторов пока не является типовым решением. Проект может стать прототипом для дальнейшего развития.
